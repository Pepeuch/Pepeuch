
# Salut ! 👋

Je suis passionné de robotique, d'électronique,

## 🤖 Mes projets

### 🌱 MowgliNext
Développement d'une plateforme de tondeuse
robotisée autonome basée sur ROS 2.

- Navigation GNSS RTK
- Évitement d'obstacles par LiDAR
- Compatibilité ArduPilot / MAVROS
- Navigation autonome avec Nav2

### 🛰️ Universal GNSS
Développement d'un pilote GNSS universel
pour ROS 2 et systèmes embarqués.

- Unicore UM98x
- u-blox F9P
- RTCM / NMEA
- Intégration ROS 2 et MAVLink

### ⚙️ Systèmes embarqués
- STM32 / ESP32
- Raspberry Pi / Rock 5B
- ArduPilot / ArduRover
- CAN Bus / UART / SPI / I2C
